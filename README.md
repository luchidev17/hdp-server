# H.D.P. - Juego de Cartas (App Móvil) 🃏

Una versión digital multijugador inspirada en el clásico juego de cartas de humor para adultos. Esta aplicación móvil permite a los usuarios unirse a partidas en tiempo real, jugar sus cartas blancas y competir para convencer al juez de turno.

**[¡Prueba la versión web aquí!](https://hdp-fake.vercel.app/)**

##  Características Principales

*   **Multijugador en tiempo real:** Salas de juego sincronizadas para partidas con amigos.
*   **Roles dinámicos:** En cada ronda, un jugador asume el rol del "Juez H.D.P." para leer la carta negra y elegir la respuesta ganadora.
*   **Cartas Blancas y Negras:** Lógicas de juego fieles al formato original.
*   **Sistema de puntuación:** Seguimiento automático de los puntos acumulados por cada jugador para definir al ganador.

##  Tecnologías Utilizadas

*   **Frontend Mobile:** Construido con Expo (React Native).
*   **Backend:** Servidor alojado y desplegado en Render.
*   **Despliegue Web (Demo):** Vercel.
